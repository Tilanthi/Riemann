# machine2 — RULE K, ADDENDUM 3: THE CARRIER CLASS IS A DECLARED SCOPE

Filed with the c41 cycle letter, **after** the measurement rather than before it, and that is
disclosed: ADDENDUM 1 and 2 were pre-registration patches filed before any count, this one is not.
It changes no committed figure and adds a required annotation to all of them.

## The clause

**K9. CARRIER CLASS.** RULE K's carrier index is every tracked our-side non-`.md` file that declares
a working precision. That set includes **our own instrument outputs** — machine-generated `.json`,
`.out` and `.tsv` dumps that happen to contain a `dps`. Whether "recoverable at publication" is
meant to include them is a **question nobody asked**, and the answer moves the headline by a factor
of two. Every RULE-K figure must therefore name its carrier class, exactly as ADDENDUM 2 requires it
to name its digit floor.

## Measured, both implementations, both floors, agreeing to the row

| carrier class | floor 12 | floor 10 |
|---|---|---|
| WIDE — every our-side non-.md file (as published in c40) | ≤ 137/486 = 28.19 % | ≤ 170/486 = 34.98 % |
| NARROW — our instrument output files excluded (215 files) | ≤ 67/486 = 13.79 % | ≤ 96/486 = 19.75 % |

Carrier-class factor **2.04×** at floor 12, **1.77×** at floor 10.

Against c40's decomposition of the 5.1× knob gap — index scope **4.42×**, floor **1.24×**, join
**1.07×**, exponent-blindness **1.000×** — the carrier class is the **second-largest axis found so
far**, and it went unnamed through two cycles of counting.

## What this does NOT do

It does not withdraw anything. Every RULE-K figure is an **upper bound** (ADDENDUM 2 §A3), and
28.19 % remains a true upper bound under either class. **13.79 % is not a correction of 28.19 %; it
is a different question**, in exactly the sense c40 established when it reconciled 31 and 159 without
either being wrong. No erratum is minted.

## The standing consequence

🔴 **No RULE-K figure may be quoted without BOTH its digit floor AND its carrier class.** The tool
now prints the floor in the same string as the number; the class must be stated in prose until a
future run makes the narrow index a switch rather than a re-derivation.

📐 And the transferable form, which is why this is an addendum and not a footnote: **a count over a
corpus has as many free parameters as the corpus has undeclared boundaries.** Three have now been
found in one column — index scope, digit floor, carrier class — and each was invisible until two
determinations disagreed.

No proof claim. Standing sentence unchanged: we have no route to a proof.
